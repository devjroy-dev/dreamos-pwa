Today gets its stature

The whole visual cluster in one picture, in the shipped Graphite and Chalk tokens — not approximations. Veto this, and the build matches it; the parity pass proves the match. Phase 4's live feed inherits the treatment as its spec.

What changed, and why. ① The dock is now an input, not a logo row: a rounded field, muted placeholder carrying one real ask, send-glyph at the right. ② Today has a masthead — date, then a numeral in Italiana, then a metal hairline — so the page opens on a moment instead of on body copy. ③ The promise line is the hero, set in Cormorant at 24px, and 「Today is still being built」 drops to a quiet line beneath it: the honest statement stays, but it stops being the headline. ④ Signal is used sparingly — one card carries a 2px signal edge, the send glyph is filled, everything else stays ink. ⑤ The DR medallion is the coin everywhere. ⑥ The wa.me link renders as itself, monospace, tap-to-copy.
Type, unified — the proposal inside item ③+⑦. Four families exist and each gets exactly one job, everywhere: Italiana — numerals and the masthead moment only. DM Sans — all prose, in rooms as well as the shell. Jost — every micro-label. Cormorant — retired from prose and kept for one deliberate line per surface: Today's hero and the sheet header. That last is the actual cure: the rooms currently set body copy in Cormorant italic while the shell sets it in DM Sans, and that — not size — is why they read as two font worlds. Three things I could not decide for you, flagged rather than drawn.
· The coin's drawer. ④ merges two identities, but the rooms' medallion drawer carries rows the shell has never had — Discover Profile, Tips & Features, The Dream Wedding, Sign Out — plus the DISPLAY section whose two entries still read Espresso and Parchment. Adopting the medallion means adopting that drawer. The mock draws the coin, not the drawer; the drawer's contents want their own pass.
· The filter chips. Shown in signal here, which is the correct end state — but they are part of the 42-site raw-CSS-var class ZIP 5's split was blind to, so this is a promise the code does not yet keep.
· 「Ask TDW」 versus DreamAi. The dock says Ask TDW; the Rooms row and the manual say DreamAi. That is two names for one thing on one screen. The ruling names both, so I have drawn both — but it wants one word from you before it ships.
