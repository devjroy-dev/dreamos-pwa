The imagery rule — 4:5, full bleed, zero radius Moments renders photographs at 54 × 54 with an 8px radius today (:3523). A photo diary whose photographs are 54px is a thumbnail list wearing a diary's name, and it is the furthest thing in the app from 「 Vogue catalogue, full bleed 」. One ratio, one treatment, edge to edge: a photograph is not a card.
The ornament string retires as a device, not as information The vertical thread at :3492 exists to relate a 54px thumbnail to its date. At full bleed there is no thumbnail column for a thread to run beside — so the same information moves onto the plate: the day rule between groups, the stamp on the image. The money register is law, not style Rs X,XX,XXX, en-IN grouping, zero glyphs, zero shorthand — as formatRs() already emits. The figure rises 15px → the body floor, and R-U24's no-truncation clause holds: a money figure renders whole or not at all. DECLARED GAP: whether Rs 8,20,000 at 16px still clears the right column at 390px is not measured at this seat — there is no browser here. It is a founder-device witness, and F-09.58's ledger strip is the precedent for exactly this failure mode. If it clips, the cure is minWidth:0 on the body and a measured fit, never a smaller figure and never compaction.
Two row species, one rhythm Bookings carry a balance; enquiries carry a state and a WhatsApp door. Today they run at 15/16px names with 6.5px and 7px metas at three different trackings. One name size, one meta size, one tracking — the difference between the species stays legible because the right-hand element differs, not because the type does.

The three forks this page rules

What your approval decides

Fork 1 · imagery treatment

A — full bleed, 4:5, zero radius · DRAWN in class 2
The photograph owns the measure. Chosen because the north star says it in three words and because a 54px thumbnail is not a photograph.
B — framed, gutter margins, 8px radius
The photograph sits inside the page rhythm like a card. Quieter, safer, and closer to the vendor lane's card discipline — but the vendor lane is an instrument and this is a diary.

Fork 2 · the slice rail's composition

A — retype in place · DRAWN in class 1
Eleven equal rows, same order, same flex distribution. Label 17 → 22px, one hint tracking, one hairline weight. No behaviour moves.
B — content-driven row heights · REFUSED, not offered
At eleven rows the rail would scroll. That is a behaviour change and L4 forbids it. Named here so the refusal is on the record rather than invisible.

Fork 3 · the masthead's typographic hierarchy

A — the numeral dominant · DRAWN in class 1
The greeting is warm but constant; the number is the only thing on the screen that is different today than it was yesterday. One loud voice, everything else a whisper.
B — the greeting dominant
Italianno at 64px+, the numeral demoted to an engraved line. Warmer on first open, and it makes every morning look identical.
A fourth fork is already ruled F-09.159 — CanvasShell paints from the legacy MODES family, whose secondary ink is 0.65α against V2's 0.75α, so the seven standalone journey screens run a darker soft-ink than the canvas. The relay places its cure inside BUILD-ALL. Folded at the CanvasShell seam only: token-level, one file, survives TDW_13's extraction.
If you veto an arm Say the fork number and the letter. Nothing else in the page depends on a fork except its own class — Fork 1 changes class 2 alone, Fork 3 changes class 1 alone. They are separable on purpose, so a single dislike does not cost the whole page.
