## 6 · F-10.32 — TWO PROPERTIES, TWO PROBLEMS, ONE DECLARED GAP

`lining-nums` at **every** figure site (legibility). `tabular-nums` at **exactly one** — the queue, where figures sit in a fixed 42px gutter against a text block and a count ticking 10→11 would reflow the label. The masthead deliberately does **not** take it: each figure sits alone in its own card with no column to align against, so tabular buys nothing there and costs the proportional spacing Cormorant was chosen for.

**THE GAP, ASSERTED AS A GAP.** The bench proves the property *resolves* at each site. It **cannot** prove the glyph changed: whether the served Cormorant Garamond woff2 carries an `lnum` set is a property of the **face**, and `fonts.gstatic.com` is outside the container's egress allowlist — the same declared gap that blocks `next build` here. A declaration-only green would go green over an unchanged glyph, which is the vacuous shape.

**The founder's eye is the verdict**, and the fallback is pre-named so no second sitting is spent choosing one: if `1` still reads as `I`, the figures move to **Italiana**, which `app/layout.tsx:8` already designates the estate's numeral face in its own words. That fallback is derived from the tree, not preferred by me.
